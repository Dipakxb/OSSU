## `Notes`

#### Notation and Symbols 
In the past you may have used the notation 3 X 5 to denote multiplication. 
In algebra it is best to avoid this notation if possible,
because the multiplication symbol X can be confused with the variable x when written by hand.

#### Real Numbers 
If there is no sign (+ or -) in front of a number, 
the number is assumed to be positive (+).

There are other numbers on the number line that you may not be
as familiar with. They are irrational numbers such as pie, under root 2,
under root 3. We will introduce these numbers later in the chapter.

In past math classes you may have written fractions 
	like 
	7/3(improper fractions) 

As mixed numbers, such as 
	 2:1/3

In algebra it is usually better to write them as improper
fractions rather than mixed numbers.



## `Definition` 
#### Real Numbers

##### Coordinate 
The number associated with a point on the real number line 
is called the coordinate of that point.
##### Real number 
The numbers that can be represented with points on the real
number line are called real numbers

##### Fraction
If a and b are real numbers, then the expression
b/a ...where... b != 0
is called a fraction. The top number a is called the **numerator**, and the bottom
number b is called the **denominator**. The restriction b !=  0 keeps us from
writing an expression that is undefined. (As you will see, 
division by zero is not allowed.)
##### Equivalent 
Fractions that represent the same number are said to be equivalent. 
Equivalent fractions may look different, but they must have the same value.

`Property 1` 
Multiplying the numerator and denominator of a fraction by the
same nonzero number never changes the value of the fraction.
`Property 2` 
Dividing the numerator and denominator of a fraction by the
same nonzero number never changes the value of the fraction.

##### Absolute Value
The absolute value of a real number is its distance from zero on
the number line. If x represents a real number, then the absolute value of x is
written | x |.

##### Opposites
Numbers the same distance from zero but in opposite directions from zero are called opposites.

Opposites always have the same absolute value. 
And, when you add any two opposites, the result is always zero:
	a + (-a) = 0

##### Reciprocals
Two numbers whose product is 1 are called reciprocals.
